# Player Radio Onda Rossa

Un player Android semplice e leggero per ascoltare **Radio Onda Rossa**.

## Funzionalità
*   **Integrazione di Sistema:** Riconosciuto da Android come lettore multimediale standard.
*   **Controlli Media:** Supporta i comandi Play/Pausa nativi dalla schermata di blocco, dalle notifiche e dai dispositivi Bluetooth.
*   **Metadati:** Visualizza il titolo della traccia corrente o del programma in onda.

## Download e Installazione
Non è necessario compilare il progetto per utilizzare l'app.

1.  Vai alla pagina delle [Releases](https://github.com/SuperSimonZzz/Radio_Onda_Rossa/releases).
2.  Scarica il file `RadioOndaRossa.apk`.
3.  Installalo sul tuo dispositivo Android (potrebbe essere necessario abilitare l'installazione da origini sconosciute).

## Dettagli Tecnici
Questo progetto è open source ed è sviluppato utilizzando tecnologie Android standard.

*   **Linguaggio:** Kotlin
*   **Motore Audio:** ExoPlayer
*   **Architettura:** Service-based (riproduzione in background persistente)
*   **Min SDK:** API 21 (Android 5.0)
